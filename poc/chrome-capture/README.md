# Chrome P0 只读验证版

这是独立扩展，不替换 V1，不连接 OpenViking，不采集 SSE，不主动发 ChatGPT 请求。

## 安装

在 Chrome 的扩展管理页加载本目录。它请求读取 chatgpt.com 的权限，需要用户确认安装。安装后刷新测试标签，主世界采集桥才会在页面初始化前安装。

## 验证顺序

1. 打开一个已有会话并刷新，打开扩展 popup 查看是否记录自然详情响应。
2. 点击“核对当前 DOM 消息 ID”，比对当前 DOM 与已收到响应中的 ID。只证明当前样本，不能推广全部历史。
3. 记录“发送前”，正常发送一条合成测试问题；回复后记录“回复完成后”，看其间是否有新的详情响应。
4. 分别测同标签 A→B→A、前进后退、新标签打开、恢复关闭标签、普通刷新、强制刷新；检查响应时间，不只看页面是否有正文。
5. 对长会话上滑，检查 query 参数和 pageInfo，核对交叠 ID。查询参数仅保存白名单值，未知参数保留名称但遮蔽值。
6. 导出诊断报告交叉核对。报告有消息 ID/时间/模型，无正文；不自动上传。

## 限制与安全

- Chrome 文本样本已通过实网采集；其余场景见下方验证结果，本地单元测试不等于完整实网验收。
- 只有显式非临时、非 do-not-remember 的响应才保存可见正文；原始响应、system 和内部 reasoning 正文不持久化。
- MAIN-world 页面通信可能被同页脚本伪造。来源/schema/体积/频率校验只降低风险，不证明真实性。
- 仅保存最近 40 个事件、合计约 4 MiB 的诊断环形记录，旧记录滚动覆盖。这不是正式 outbox。
- 响应复制上限 2 MiB、并行 2、读取超时 15 秒。超限会标示采集失败，原始网页响应不取消；复制流的实际内存行为仍要浏览器验证。
- 默认仅支持样本已证实的扁平 messages[] text 格式；未知类型、隐私标志缺失、非 JSON 返回明确失败或排除。
- DOM 检查只在用户点击时执行，不监听整页、不定时扫描。没有观察到响应时，不能推断没有新消息。
- V1 若仍开启自动同步，浏览测试会话可能被 V1 上传；执行合成 ChatGPT 测试前应暂停 V1 自动同步并记录原设置，测试后再按用户决定恢复。

运行单元测试：`node --test test/p0-capture.test.js`（项目根目录）。

## 当前验证结果

Chrome 自然详情响应已有样本验证。成功新轮次未必产生详情；一个合成样本在普通刷新后补录两条。语音/多模态未支持，真实分页与标签恢复仍需补证。公开结论见 [测试说明](../../docs/public/TESTING.md)，不分发私人原始诊断。

`../reconcile-snapshot.js` 是尽力去重纯函数验证原型，不在本扩展中执行、不连接生产上传器；它不是已经上线的跨设备去重功能。
