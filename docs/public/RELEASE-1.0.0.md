# 1.0.0 — Chrome 正式版

将 ChatGPT 自然加载的会话文字同步到 OpenViking，保留源消息身份与时间，提供持久队列、回读确认及清晰的同步状态。

## 本次更新

- 修复较早历史分页未被采集的问题：详情与历史分页响应统一按源消息 ID 合并，重叠页不重复入队。
- 保留图文提问中的文字，明确提示图片和其他非文本部分未同步；不会把资源对象或工具输出拼成正文。
- 使用原始 `create_time`，保留源时间的小数精度；缺少有效时间的消息单独提示，不再使用 DOM 推断时间。
- 区分本机已采集、远端已确认、等待上传确认，并根据最近响应的分页信息给出操作建议。
- 修复升级后旧页面上下文失效引起的未捕获转发异常；采集错误按目的地和会话隔离，避免其他会话错误干扰当前状态。
- 统一设置、弹窗和安装说明，补充安全错误分类与处理步骤，不记录原始异常中的私密内容。

## 下载与安装

- `chatgpt-openviking-v2-1.0.0.zip`：Chrome 安装包，仅含运行所需文件及安全说明。文件名中的 v2 表示 API 响应采集架构，无需另外安装 V1。
- `chatgpt-openviking-source.zip`：脱敏源码、合成测试与公开文档。
- `SHA256SUMS`：两个压缩包的 SHA-256 校验值。

解压安装包，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，选中含 `manifest.json` 的目录。详细配置与使用方法见仓库 README。

已有安装请保留扩展身份、配置和本地队列，更新原安装目录后重新加载扩展。先保存草稿并等待回复完成，再刷新 ChatGPT 会话；按需上滑加载较早历史。不要为升级而删除或重建远端 Session。

## 验证范围

- 125 项功能回归、2 项打包测试；清单校验、构建及公开文件脱敏检查通过。
- macOS Chrome 的 14 条、24 条真实长会话完成分页补录与远端确认；刷新、重复加载及同安装双标签测试未发现重复增长。
- 合成测试覆盖 14、24、120 条多页消息，逐项核验来源 ID、角色、正文与时间。
- 补充人工验收反馈未发现漏采。Windows/macOS/Linux 的 Node CI 不等同于各系统浏览器实机验收。

## 使用边界与观察项

- 同步范围是 ChatGPT 自然加载的支持文字消息，不是全账户、全分支或附件备份；未实现 SSE，不保证每轮回复完成后立即采集。
- 跨设备采用写前/写后回读的尽力去重，仍存在并发重复窗口，不承诺服务端原子幂等。
- 服务端可能降低时间精度；已有历史时间不会被自动覆盖。
- 升级测试中曾观察到一次采集异常，刷新后恢复，后续未再次复现；根因尚未确认。已增加隔离诊断，保留追踪，不将其描述为已完全修复。
- MAIN world 签名用于限制转发与防重放，不认证已被攻陷页面中的数据。

完整测试记录见 `docs/public/TESTING.md`。公开问题反馈前，请移除 API Key、服务配置、会话 ID、正文、精确时间与截图中的个人信息。
