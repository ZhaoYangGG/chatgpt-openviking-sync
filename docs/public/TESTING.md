# 测试与验收

## 自动化

npm test 使用合成数据、模拟 HTTP 与 fake-indexeddb，不需凭据，不访问真实服务。覆盖原 V1/P0 及新增完整 V2：

- 原始数字文本/科学计数与小数转换、缺失时间、重复 key/深度拒绝。
- 本地身份去重、元数据变化、修订、容量原子回滚。
- 写前/后回读、lost_ack 与重开恢复、远端重复、单条冲突、移动水位、未知来源。
- 禁用保护、网络期间修订、双设备独立数据库的竞态恢复。
- 签名生成/验签、篡改/重放/跨文档拒绝、未签名载荷拒绝。
- 扩展升级后旧页面上下文失效时，转发通道同时处理同步抛错和异步拒绝，避免未捕获异常。
- 采集错误按目的地与会话隔离；其他会话的成功不会清除本会话错误，切换目的地不会继承原错误。错误写入按序执行，避免旧失败覆盖后续成功。
- 错误诊断仅保存固定分类、阶段和处理步骤；注入失败与 JSON 解析失败不保存原始异常文本。
- 精确详情/历史分页白名单、同文档同目的地隐私上下文、隐私撤销、错会话和缺少验证拒绝。
- 分页顺序/源时间数字精度、重叠分页与重开去重、标题保留；图文仅提取字符串，不保存资源对象。
- 已收到但零可接纳的状态，以及跨页保留“图文仅同步文字”提示。
- 完整 Worker 配置门控、复用 V1 Session、实际客户端 HTTP 载荷、源 ID 不重复拼接、源时间、账户空间隔离。
- 状态优先级、已确认与隔离计数、分页未知/有前页/无更多页的边界文案。
- 弹窗读取超时与恢复、重试不冒充上传成功、刷新确认及目标会话校验、文本安全渲染。
- 角标事件防抖、双标签复用摘要、不变状态不重绘、离开会话清除和读取失败撤销成功标记。

npm run test:release 另测脱敏拒绝、白名单导出与防覆盖。CI 分别运行 Linux/Windows/macOS Node 测试；不是浏览器实机验收。

## 浏览器证据边界

此前 0.2.0 只读预览在 macOS Chrome 的样本 messages/outbox 为 6/6，双标签/刷新不增长；合成首轮普通刷新后采到两条。不能把这份旧证据当作完整 0.2.1 签名桥/上传的实机通过证明。

新增合成消息的浏览器验证应使用隔离服务；已有消息同步验证须由数据所有者明确授权。未实际执行的 Windows Chrome、缓存恢复、长时间性能、真实云实例迁移不能标成已完成。

0.2.2 状态面板改动的本机 macOS Chrome 冒烟覆盖：原扩展同 ID 重载、版本显示、既有采集/确认数量、工具栏提示、分页文案、补录前取消与确认。此检查不替代 Windows 实机、网络故障和并发上传验收。

## 隔离流程

1. 取得安装/权限与测试授权。
2. 记录并临时暂停旧上传器，避免合成数据进入真实服务。
3. 在独立 V2 配置使用本机模拟服务或已确认隔离的测试实例。
4. 自然打开/刷新合成会话，检查消息、时间、source ID 与服务器回读。
5. 双标签/刷新验证不重复；停止模拟服务后验证恢复。
6. 测试结束停止 V2 测试上传、关闭合成标签、恢复旧设置。关闭标签不删除会话。

P0 诊断环导出仍可能含隐私，禁止原样公开。手动服务实验会创建/追加 Session，不自动销毁；无法证明关闭记忆/commit 的实际隔离效果时不要使用生产服务。
